# Train/test overlap in the fine-tuned baseline

Generated by `evaluation/prediction/scripts/ft_baseline_analysis.py`.

## Why this analysis exists

This paper argues that a pooled accuracy figure conflates recall of alloys a
system was built on with generalisation to alloys it has not seen. That
argument obliges us to apply the same test to the baseline we compare
against, not only to our own system.

The fine-tune corpus holds 83 alloys in its train and validation splits
and 21 held out. **19 of the 88 evaluation alloys appear in
that train/validation set by name**, with their measured property tables as
the training target. This is not near-duplication under vendor branding; it
is the same alloy designation.

Matching instead on composition, 28 evaluation alloys sit within
d < 2.0 of a fine-tune alloy -- the same cut used for the NEAR stratum
elsewhere. The name match is the conservative figure and is used below.

**NIMONIC PE16 is excluded from every table here.** Its archived baseline
predictions were generated from a composition carrying Ti = 12.0 wt%
against a datasheet value of 1.2. That error was corrected for this
system's arms; leaving it in place for the baseline would manufacture an
advantage. Re-run the baseline on the corrected composition and pass
`--keep-erratum-rows` to restore the rows.

## Reading

**The baseline's strength is concentrated on the alloys it memorised.** On
yield strength the fine-tune scores 88.80 MPa on the alloys it was trained
on against 105.39 MPa on the rest. On those same memorised alloys the full
agent system scores 94.06 MPa -- it does not win there. On the alloys the
fine-tune never saw, the agent system scores 74.06 MPa against the
baseline's 105.39.

This mirrors the knowledge-graph anchoring result exactly, with the roles
reversed: a retrieval-shaped advantage that exists only where a stored answer
exists, and disappears where one does not.

**Elastic modulus is the honest loss.** The fine-tuned baseline reaches
8.17 GPa against 8.25 GPa for ML+physics+KG and
8.95 GPa for the full agent system. A single
fine-tuned small model is the best elastic-modulus predictor measured here,
and no arrangement of this system's components beats it on that property.

## Caveats

- Name matching is exact after normalisation, so a fine-tune alloy sold under
  a different vendor name is counted as UNSEEN. The overlap is a lower bound.
- The UNSEEN group is not clean for *this* system: its ML ensemble and
  knowledge graph were built on 77 alloys with their own overlap with the
  evaluation set. This table isolates the fine-tune's leakage, not all leakage.
- The two systems' training sets are different, so SEEN/UNSEEN is a property
  of the baseline only. Per-group sample sizes fall below 100 rows.
